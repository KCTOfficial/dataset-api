# AksaraGo question bank

Static JSON questions and answers for the AksaraGo learning app (SD, SMP, SMA).
Everything here is generated or checked by the tools in [`../tools/aksara-go/`](../tools/aksara-go/);
run `python -I tools/aksara-go/validate.py` before publishing any change.

## Layout

```
aksara-go/
+-- manifest.json          <- start here: every game and file, with counts, SHA-256 and review status
+-- <game-id>/
    +-- meta.json          <- title, instruction, interaction, colors, segments, review records
    +-- <segment>.json     <- one file per education segment the game supports
```

Segments follow Kurikulum Merdeka phases:

| segment | jenjang | grades |
|---|---|---|
| `sd-a` | SD | 1-2 (Fase A) |
| `sd-b` | SD | 3-4 (Fase B) |
| `sd-c` | SD | 5-6 (Fase C) |
| `smp` | SMP | 7-9 (Fase D) |
| `sma` | SMA | 10-12 (Fase E-F) |

A game that doesn't support a segment simply has no file for it.

## Question file

```json
{
  "schemaVersion": 1,
  "gameId": "hitung-cepat",
  "segment": "sd-c",
  "jenjang": "SD",
  "interaction": "NUMPAD",
  "questions": [ ... ]
}
```

Each question:

| field | required | meaning |
|---|---|---|
| `id` | yes | `<gameId>.<segment>.<NNNN>`, unique across the dataset. Never reused once published. |
| `difficulty` | yes | 1-5. Files are sorted by difficulty. |
| `prompt` | yes | Object with at least `text`, plus optional `hint`, `emoji`, `number`, `letters`, `sequence`, `left`, `right`. |
| `answer` | yes | String or integer, depending on the interaction. |
| `interaction` | no | Overrides the file's default interaction for this question. |
| `payload` | no | Interaction-specific data (`options`, `distractors`, `relation`, `rule`). |
| `explanation` | no | One short Indonesian sentence shown after answering. |

The data never says *how* a level presents an answer (letter tiles, word tiles, or typing).
The app decides that, so one question can be reused across levels.

## Interactions

### `NUMPAD`: integer answer (optional 4 `options` for a multiple-choice fallback)
```json
{"id": "hitung-cepat.sd-c.0001", "difficulty": 2, "prompt": {"text": "2 + 4 × 5"}, "answer": 22, "payload": {"options": [22, 30, 21, 23]}}
```

### `TILE_BANK`: assemble the answer from tiles; `distractors` are extra tiles
```json
{"id": "tebak-angka.sd-b.0001", "difficulty": 4, "prompt": {"text": "2020", "number": 2020}, "answer": "dua ribu dua puluh", "payload": {"distractors": ["ratus", "tiga", "belas"]}}
```

### `FILL_GAP`: `_` marks each missing letter
```json
{"id": "lengkapi-kata.sd-a.0001", "difficulty": 2, "prompt": {"text": "H_RI_A_", "hint": "Hewan buas bergaris", "emoji": "🐯"}, "answer": "HARIMAU"}
```

### `MULTI_CHOICE`: pick one of 2-4 `options`
```json
{"id": "kata-baku.smp.0001", "difficulty": 1, "prompt": {"text": "Mana penulisan yang baku?"}, "answer": "apotek", "payload": {"options": ["apotek", "apotik"]}, "explanation": "Bentuk baku menurut KBBI adalah apotek."}
```

### `MATCH_PAIRS`: the matching word for `prompt.text`, with its `relation`
```json
{"id": "sinonim-antonim.sd-b.0001", "difficulty": 1, "prompt": {"text": "besar"}, "answer": "kecil", "payload": {"relation": "antonim", "options": ["kecil", "luas", "tinggi", "berat"]}}
```

### `COMPARE`: the answer is `<`, `>` or `=`
```json
{"id": "banding-angka.smp.0001", "difficulty": 2, "prompt": {"text": "3/4 ? 0,7", "left": "3/4", "right": "0,7"}, "answer": ">"}
```

## Number formatting

- Display text uses Indonesian formatting: `.` for thousands from 10.000 upward (`1.250.000`), `,` for decimals (`3,25`).
- Four-digit numbers have no separator (`2020`), the way children see years.
- Operators in display text: `×`, `÷`, and `−` (U+2212). Never `*`, `x`, or ASCII `-`. Exponents are superscripts (`2³`); logarithms use Indonesian notation (`²log 8`).
- Machine-readable values (`answer`, `payload`) are plain JSON numbers.

## Manifest

```json
{
  "schemaVersion": 1,
  "datasetVersion": "1.0.0",
  "games": [
    {"gameId": "hitung-cepat", "meta": "hitung-cepat/meta.json", "metaSha256": "...",
     "files": [{"path": "hitung-cepat/sd-a.json", "gameId": "hitung-cepat", "segment": "sd-a",
                "jenjang": "SD", "questionCount": 120, "sha256": "...", "status": "reviewed"}]}
  ]
}
```

- `sha256` is computed over the file's exact bytes. A client whose cached copy has the same digest doesn't need to download again.
- `status` is `reviewed` or `draft`. Procedural games (answers recomputed by the validator) are `reviewed` once valid. Curated games stay `draft` until a human review is recorded in `meta.json` under `review.<segment>` (`sha256`, `date`, `role`), and they fall back to `draft` automatically if the file changes after review.
- The manifest is generated by `tools/aksara-go/build_manifest.py`; never edit it by hand.

All files are UTF-8 without BOM, with LF line endings and 2-space indentation (see `.gitattributes`).
